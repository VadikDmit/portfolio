# ТЗ: Сайт-портфолио Вадима Дмитриева

## 1. Цель проекта

Создать персональный сайт-портфолио Вадима Дмитриева в стиле современного digital/creative portfolio.

Основная специализация:

**UX/UI Designer | Vibe Coding**

Сайт должен одновременно демонстрировать:
- уровень визуального дизайна;
- UX/UI-компетенции;
- умение создавать современные веб-интерфейсы;
- навык разработки сайтов с помощью AI / Vibe Coding;
- внимание к деталям, типографике, анимации и интерактиву.

В качестве визуального и UX-референса использовать сайт:

https://www.gabrielbeaugonin.com/

ВАЖНО: не копировать сайт буквально. Нужно изучить его визуальный язык, композицию, типографику, навигацию, работу с hover-состояниями, переходы и анимации, а затем создать оригинальную реализацию для Вадима.

---

# 2. Общий принцип

Сайт должен ощущаться как персональное digital-портфолио дизайнера, а не как обычный корпоративный сайт.

Ключевые характеристики:

- минимализм;
- большое количество свободного пространства;
- крупная типографика;
- визуальная иерархия;
- нестандартная, но понятная навигация;
- аккуратные hover-анимации;
- плавные переходы между страницами;
- минимальное количество декоративных элементов;
- акцент на проектах;
- ощущение дорогого digital-продукта.

Не использовать типовой шаблон:
Hero → About → Services → Projects → Contacts.

Главная должна быть максимально простой и характерной.

---

# 3. Технологический подход

Сайт необходимо сделать как полноценный современный web-проект.

Предпочтительный стек:

- Next.js
- React
- TypeScript
- Tailwind CSS или чистый CSS
- Framer Motion / GSAP для анимаций
- современная архитектура компонентов

Если Claude Code считает другой стек более подходящим, можно использовать альтернативу, но итог должен быть:
- быстрым;
- адаптивным;
- SEO-friendly;
- легко редактируемым;
- готовым к деплою.

Не использовать тяжелые библиотеки без необходимости.

# 5. Поведение списка проектов

Список проектов должен быть одним из главных интерактивных элементов сайта.

При наведении на проект:

- название меняет состояние;
- появляется превью проекта;
- превью может следовать за курсором или появляться рядом со списком;
- переход должен быть плавным;
- желательно использовать легкий scale / opacity / position transition;
- не использовать чрезмерные эффекты.

Если реализация floating preview усложняет UX, использовать аккуратное появление изображения справа/слева от названия.

На мобильных устройствах hover-механику заменить на понятное tap/scroll-поведение.

# 11. Визуальный стиль

Ориентироваться на референс Gabriel Beaugonin.

Основной стиль:

- editorial;
- minimal;
- premium;
- digital;
- typography-first.

### Цвет

Предпочтительно начать с нейтральной системы:

- background: #F5F5F3 / близкий теплый светлый оттенок;
- text: почти черный;
- secondary text: серый.

Но цветовую систему необходимо вынести в отдельные CSS variables, чтобы ее можно было легко изменить.

Не использовать много цветов.

---

# 12. Типографика

Типографика — один из главных элементов дизайна.

Использовать современный гротеск.

Рекомендуется рассмотреть:

- Inter;
- Geist;
- Helvetica Neue;
- Arial;
- или другой современный neutral grotesk.

Для крупных заголовков использовать большой размер и плотную типографическую композицию.

Примерная логика:

Desktop:
- Display: 64–120px;
- H1: 64–96px;
- H2: 40–64px;
- body: 16–20px;
- metadata: 12–14px.

Точные размеры определить после визуальной реализации.

Важно добиться выразительности не за счет декоративных эффектов, а за счет типографики и пространства.

---

# 13. Сетка

Desktop:

- max-width: 1600px;
- боковые отступы ориентировочно 40–80px;
- использовать responsive grid.

Не привязывать весь сайт к одной жесткой ширине.

Для больших экранов контент должен сохранять аккуратную композицию.

Mobile:

- 16–24px боковые отступы;
- одна колонка;
- крупная типографика;
- удобные touch targets.

---

# 14. Анимации

Анимации очень важны для общего ощущения сайта.

Использовать:

### Page transition

При переходе между страницами:
- fade;
- slight vertical movement;
- duration примерно 400–700ms.

### Hover

Для проектов:
- изменение цвета/opacity;
- появление preview;
- небольшое движение;
- scale 1.02–1.05.

### Images

Изображения могут:
- плавно проявляться;
- слегка масштабироваться;
- двигаться при наведении.

### Cursor

Можно добавить кастомный cursor на desktop.

Но:

- он не должен мешать;
- не должен ухудшать usability;
- на mobile отключить.

Не использовать чрезмерную анимацию.

Каждое движение должно создавать ощущение качества.

---

# 15. Responsive

Сайт обязательно должен корректно работать:

- 1440px+
- 1280px
- 1024px
- 768px
- 390px
- 375px

Desktop и mobile могут иметь разную композицию.

На mobile:

- убрать cursor effects;
- убрать hover-only взаимодействия;
- адаптировать список проектов;
- сохранить крупную типографику;
- обеспечить удобную навигацию;
- не допускать горизонтального overflow.

---

# 16. Accessibility

Обязательно:

- semantic HTML;
- правильная структура headings;
- alt для изображений;
- keyboard navigation;
- visible focus states;
- достаточный contrast;
- `prefers-reduced-motion`.

При отключенной анимации сайт должен оставаться полностью функциональным.

---

# 17. Performance

Сайт должен быть быстрым.

Требования:

- оптимизация изображений;
- lazy loading;
- минимизация JavaScript;
- не использовать тяжелые видео без необходимости;
- использовать Next.js Image;
- не загружать все изображения проектов сразу;
- анимации должны быть GPU-friendly.

**«Это портфолио современного UX/UI-дизайнера, который умеет не только проектировать интерфейсы, но и самостоятельно превращать дизайн в работающий продукт с помощью Vibe Coding.»**

- стандартный сайт фрилансера;
- обычное резюме;
- generic AI-generated landing page.

Главная задача — показать **вкус, уровень дизайна и способность создавать digital experiences**.
